# Evaluation repairs and local dataset validation

## Implemented

- Full clip/person/state/degradation identifiers now define an episode. Only the exact restorer suffix is removed. Conflicting labels, captured scores, qualities, grids and duplicate candidates fail validation.
- Corrected exploratory benchmark: 20 episodes, 705 timestamps, seven sources. The previous 18-episode benchmark is invalid for comparisons.
- Agent answers must cover the entire label grid. Invalid labels and decision strings are rejected. Zero answer coverage has no defined error rate.
- Controller consistently uses eight turns and 24 tools. After evidence inspection and comparisons it forces submission from turn five. It no longer forces a captured answer when evidence is incomplete.
- A 401 credential retry rebuilds authorization headers. Rate limiting does not rotate credentials.
- Historical agent formats are explicitly adapted and rescored. Twenty three-video and 24 transfer runs were previously skipped. Incomplete runs remain distinct; missing counts are never imputed as zero.
- Mixed selections record actual evidence origin. Sparse whole-clip IQA is not presented as the quality of a mixed output. Abstention comparisons report captured errors on the same answered timestamps.
- Unmeasured audio interventions are now missing, not fabricated. The old final-suite entry point is disabled because it does not implement the proposed CTS method. Historical raw measurements and outputs are preserved.
- Local AVA runners accept an explicit dataset directory, media manifest and frozen episode identifier. New bundles are written into the new run directory, preserving previous arrays.
- Audio resampling may trim at most 16 excess samples at 16 kHz (1 ms), with the exact number logged. Missing audio and larger discrepancies still fail.

## Data checks

The local Final Experiments data directory contains 176 media files: 33 with audio and video, 64 video-only and 79 audio-only. All expose readable stream headers. AMI camera and microphone files are naturally separate; this inventory does not establish their synchronization.

Four AVA sources had separately downloaded video/audio components. These were remuxed without re-encoding into data/ava/merged_v2 in the Final Experiments checkout. Original components were preserved. All 25 AVA sources pass a one-second audiovisual decode at their first annotated timestamp. This does not replace checking face identity, native resolution, audio synchronization and annotation applicability for selected clips.

## Remaining method work

The masked captured-support verifier and independently calibrated selection policy still require implementation and validation. The repaired baseline evaluator deliberately does not masquerade as that method. All previously inspected sources are exploratory; a new source-disjoint train/calibration/test protocol must be frozen before learning or selecting thresholds. AMI label and camera/audio alignment validation remains required. Existing provider runs have different budgets/protocol versions and cannot establish a fair model ranking.
