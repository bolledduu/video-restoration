# Model feasibility audit — 2026-10-12 (America/Los_Angeles)

**Execution update, 2026-10-13:** the official Ear-for-Face-SR checkpoint now runs on this laptop through a TF1 compatibility adapter. Three author examples / 12 single-image CPU passes are recorded in `results/ear_cpu_probe.json`. This is genuine audio-assisted image restoration, not temporal video restoration or speaker-attribution validation. [Execution and original-RQ preparation](ORIGINAL_RQ_PREPARATION.md) supersedes any blanket implication that no genuine audio-conditioned restoration can execute locally.

**Update:** A broader HF search found `xin1u/OmniVR` and `xin1u/JoyAI-Echo-SR` with public audio-video restoration adapters. The earlier search was too narrow to support a general model-unavailability conclusion. OmniVR author outputs are evaluated separately in `HF_CONTINUATION.md`; its local restoration inference was not executed.

For the original GAVN/DAVD-Net attempt, the blocker was an unavailable-to-that-run implementation and checkpoint. The newly found OmniVR path has a different constraint: published CUDA inference and a base checkpoint larger than laptop RAM. Searches cannot establish that no release exists anywhere. No model was trained from scratch or replaced with a lip-sync generator.

The scripts import the upstream model implementations; they do not invent approximations or train on these three examples. Large AV language models were not downloaded: the laptop had only about 1.17 GiB free RAM at the initial audit, and the prerequisite restoration outputs and verified labels are absent. This is a scoped omission, not a claim that every AV language model is impossible on CPU.

## Search record

`results/model_search_audit.json` contains actual public API responses and retrieval times. The broad `GAVN` query returns the first 30 hits only (241 total at retrieval), mostly unrelated names; the exact-title search returns zero, DAVD-Net returns an unrelated WebDAV repository, and Hugging Face searches return no relevant checkpoint. Additional web searches used the full GAVN title, authors, and DAVD-Net title. The arXiv v1 manuscript promises a future code release but does not provide a usable release link. These findings support **NO-GO for full-paper investment on current evidence** and closure of this laptop feasibility assessment. They do not establish universal nonexistence or falsify the hypothesis.

For any separate future reopening (not scheduled): obtain the official inference implementation, pretrained restoration/audio/landmark weights, permitted-use terms, and example preprocessing. Then profile one short face crop on CPU before considering different hardware. A GPU purchase alone does not resolve missing code or weights.
